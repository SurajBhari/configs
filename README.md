A collection of **[SourceMod Executes](https://github.com/splewis/csgo-practice-mode) spawn configs** for CS:GO practice servers — pre-built site-take / retake spawn setups for the competitive map pool (Dust2, Mirage, Inferno, Nuke, Overpass, Cache, Cbble, and more, including old/night variants).

The "Executes" game mode repeatedly spawns players into bomb-site execute and retake scenarios so a team can drill set plays. These configs define the player spawns, weapons, and grenades for each scenario.

> ⚙️ **Spawns are tuned for at least a 60-second round time.**

## Install

Copy the `addons/` folder into your CS:GO server's game directory so the files land at:

```
csgo/addons/sourcemod/configs/executes/<map>.cfg
```

Restart the map (or reload the Executes plugin) to pick up the configs.
